# VirtualVirtuoso
This is the repository that is going to run a web based music application with a highly interactable user interface that attempts
to replicate how an instrument would be played in real life on keyboard.

#To Run the Project Locally
1. Install the Node.js
   +https://nodejs.org/en
   Run this to verify installation: node -v npm -v
   
2. Enter the these command to enter the folder where the react project is currently being held:
  + Run this to enter that folder: cd "VirtualVirtuoso/VirtualVirtuoso copy"
  + Run this command to install the React dependencies: npm install
  + Run this command to start building the project: npm run build
  + Run this command to then host the project on your computer: npm run dev

3. Code and Have Fun
